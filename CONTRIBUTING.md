# Mitwirken

Beiträge sind willkommen, sofern keine realen Zugangsdaten oder E-Mail-Inhalte eingecheckt werden.

## Vor einem Commit

1. Projekt bauen.
2. Geänderte Funktionen lokal testen.
3. `git status` auf Backup-, Secret- oder Konfigurationsdateien prüfen.
4. Keine realen E-Mail-Adressen als Default-Konfiguration eintragen.
5. Keine `.cred`, `.mbox`, `.eml`, ZIP-Backups oder Logs committen.

## Pull Requests

Bitte kurz beschreiben:

- was geändert wurde,
- warum die Änderung nötig ist,
- wie sie getestet wurde,
- ob bestehende Konfigurationen kompatibel bleiben.
